Common Consulting Questions

Do you offer 1-on-1 Excel tutoring or only custom-built spreadsheets?

Both are available. You can book remote 1-on-1 coaching sessions covering Excel basics, clean data layout, formulas, Power Query, or Power BI, or commission a done-for-you custom workbook with a guided handover.

Do Power Query files work in Mac Excel or Google Sheets?

Full Power Query .m folder consolidation works best in Windows Desktop Excel (2016+ or Microsoft 365). Standard .xlsx formula workbooks run on both Windows and Mac, and Google Sheets adaptations can be custom-built using native formulas or Apps Script on request.

How are custom projects priced and scoped?

All custom builds and guided packages (such as XL-05) begin with a brief review and written fee quote before any payment or build begins, so scope, revision rounds, and target Excel version are agreed clearly upfront.

How should we handle sensitive employee or payroll sample files?

Please anonymize names, IDs, and salary figures into realistic synthetic sample rows while keeping your real column headers and date formats intact. That protects staff confidentiality while ensuring formulas and Power Query steps match your exact export layout.
